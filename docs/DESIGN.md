# 작은 회사의 화면과 소리

2026년 9월 22일 기준으로 확인한 자료와 이번 화면에 반영한 기준입니다. 최신 앱 사례와 오래된 게임의 표현 방식을 구분해서 참고했습니다.

위 자료의 색상표나 게임 자산을 복사하지 않았습니다. 아래 배색과 화면 구성은 이 프로젝트에 맞춰 정한 디자인입니다. 연구와 게임 자료의 발표 시점이 모두 2026년이라는 뜻은 아닙니다.

## 색과 글자

UI는 흰색과 차콜을 바탕으로 사용합니다. 주요 행동은 베리 레드, 방 안은 회보라색 바닥·목재 책상·파란 의자로 구분했습니다. 녹색은 식물처럼 사물의 의미가 있는 곳에 사용합니다.

| 용도 | 밝은 화면 | 어두운 화면 |
| --- | --- | --- |
| 화면 바탕 | `#F0F1F4` | `#22232B` |
| 패널 | `#FFFFFF` | `#292A34` |
| 본문 | `#252630` | `#F1F1F6` |
| 보조 글자 | `#666974` | `#AFB1BF` |
| 강조 글자 | `#BC304C` | `#FF98AC` |
| 주요 버튼 | `#B92D49` + 흰 글자 | 동일 |
| 장면 바탕 | `#E3E5ED` | `#292D3D` |

- **[Wanted Sans](https://github.com/wanteddev/wanted-sans)**: 한국어 본문과 조작부. 긴 작업명은 줄바꿈하고, 휴대폰의 입력창은 16px로 표시합니다.
- **[Galmuri](https://github.com/quiple/galmuri)**: 로고. 픽셀 글꼴은 작은 본문까지 확장하지 않습니다.
- 두 글꼴은 앱에 포함되어 외부 폰트 서버에 접속하지 않습니다. 원문 라이선스는 `assets/fonts/`에 있습니다.

## 계속 움직일 것과 잠깐 반응할 것

걷기·타이핑·창밖 시간은 장면의 일부입니다. 반면 완료·확인 요청은 잠깐의 효과로 알려줍니다. 모든 직원에게 상시 말풍선과 작업 카드를 띄우지 않습니다. 기본 화면에서는 캐릭터와 이름을 먼저 보고, 자세한 내용은 직원 화면에서 읽습니다.

운영체제의 ‘동작 줄이기’를 켜면 이동 애니메이션·입자·날씨 효과를 줄입니다. 모바일에서는 효과를 자동으로 줄이며, 사용자가 설정에서 조절할 수도 있습니다.

## 소리

음악과 효과음은 각각 선택해서 켭니다. 음악은 직접 작성한 전자 피아노 화음·베이스·짧은 리듬을 Web Audio로 합성합니다. 외부 음원과 게임 사운드는 사용하지 않습니다.

| 상황 | 반응 |
| --- | --- |
| 낮 / 밤 | 곡의 음역과 템포가 달라집니다. 분위기를 직접 고를 수도 있습니다. |
| 확인할 일이 생김 | 자동 모드에서는 여백이 많은 악보로 바뀝니다. |
| 출근 / 퇴근 / 작업 시작 / 완료 / 확인 요청 | 각 상황에 맞는 짧은 효과음을 사용합니다. 단순 상태 갱신은 조용히 처리합니다. |
| 여러 알림이 겹침 | 중요한 알림 하나를 고르고 반복 재생을 제한합니다. |
| 알림 재생 중 | 배경음악을 잠깐 낮춘 뒤 되돌립니다. |
| 다른 탭으로 이동 | 음악과 효과음 처리를 멈추고, 돌아오면 이어갑니다. |
| `M` 키 | 음악과 효과음을 함께 음소거합니다. |

체험 모드의 직원·통계·업적은 실제 작업 기록에 섞이지 않습니다. 작업실의 ‘확인했어요’와 ‘보류’는 이 화면 안의 표시이며, 실제 AI 도구에 승인 명령을 보내지 않습니다.
