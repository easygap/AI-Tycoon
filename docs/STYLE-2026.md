## 이 회사에 맞는 조합

색은 하늘색 `#D7EFFF`, 자두색 `#351E28`, 주황 `#FF5C34`를 중심으로, 흰색 `#FAFCFF`와 데님 블루 `#5278A5`를 받칩니다. 주황 위에는 짙은 글자를 쓰고, 작은 강조 글자는 대비가 높은 짙은 주황을 사용합니다. 본문은 Wanted Sans, 로고와 맵 간판은 Galmuri를 유지합니다.

직원들의 옷을 이번 변화의 중심으로 삼습니다. 옷깃과 소매가 다른 여섯 벌, 모자와 가방, 단정한 픽셀 실루엣으로 구별합니다. 얼굴·이름은 그대로 두고 옷만 고를 수 있어야 같은 직원을 계속 알아볼 수 있습니다.

```text
직원 목록             직원 상세
┌───────────────┐     ┌───────────────────┐
│ 얼굴  이름·상태│     │ 목록으로  이전·다음│
│       프로젝트│     │ 큰 캐릭터  이름    │
│ 지금 하는 일  │     │           맵에서 보기│
└───────────────┘     │ 옷 갈아입기        │
                      │ 지금 하는 일·메모  │
                      └───────────────────┘
```

유행 자료를 많이 모았다고 디자인이 좋아지는 것은 아닙니다. 복잡한 배경과 과도한 장식을 추가하는 대신, 캐릭터의 차이가 먼저 보이고 원하는 직원과 작업을 빨리 찾을 수 있는지를 기준으로 실제 화면을 검토합니다.
