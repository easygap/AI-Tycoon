# 화면 모아 보기

2026년 9월 22일, 실제 앱을 체험 모드로 실행해 찍었습니다. 직원 이름과 작업 내용은 예시 데이터입니다. PC 화면은 1440×960, 모바일 화면은 390×844 크기입니다.

## 작은 회사

직원들의 행동을 보면서 확인할 일이 있는지 살펴봅니다. 오른쪽 패널에서 해당 작업을 열 수 있습니다.

![밝은 테마](hero-light.png)
![어두운 테마](hero-dark.png)

## 작은 제작소 한 바퀴

둥근 회의 자리와 작업대를 중심으로 자료실과 카페 테라스가 이어집니다. ‘장면만 보기’를 켜면 맵을 넓게 볼 수 있어요.

![장면만 보기로 촬영한 전체 맵](map-studio.png)

휴대폰에서는 ‘전체 맵’ 메뉴로 원하는 공간을 골라 확대합니다.

## 직원 상세

캐릭터를 크게 보고 옷을 바꾸거나, 지금 하는 일과 메모를 확인합니다. ‘맵에서 보기’로 해당 직원에게 이동할 수 있습니다. PID·세션·메모리 정보는 ‘세션·연결 정보’를 펼쳐 확인합니다.

![직원 상세](detail.png)

## 직원 옷장

여섯 벌 중에서 고르면 맵과 직원 목록에 바로 반영됩니다. 얼굴과 이름은 그대로 유지합니다.

<p align="center"><img src="mobile-wardrobe.png" width="390" alt="모바일 옷장"><img src="mobile-wardrobe-dark.png" width="390" alt="어두운 테마의 옷장"></p>

![실제 캐릭터 그림으로 만든 코디 모음](wardrobe-lookbook.png)

## 작업 통계

오늘의 활동과 도구별 작업, 프로젝트별 진행 상태를 모아 봅니다. 체험 모드의 통계는 실제 작업과 분리됩니다.

![작업 통계](insights.png)

## 빠른 검색

`Ctrl+K` 또는 `Cmd+K`로 직원을 찾거나 자주 쓰는 기능을 실행할 수 있습니다.

![빠른 검색](cmdpalette.png)

## 캐릭터와 자세

앱에서 사용하는 픽셀 캐릭터를 정수 배율로 확대한 모습입니다. 별도 일러스트가 아니라 실제 화면과 직원 목록에 사용하는 같은 그림입니다.

![캐릭터와 작업 자세](characters.png)
