# 1.8.0 확인 기록

확인일: 2026년 9월 22일. 로컬 환경은 Windows, Node.js 24.14.0, Playwright로 실행한 Chromium입니다.

## 자동 검사

- `npm run build`: Tailwind CSS 생성 완료.
- `npm run lint`: JavaScript 48개 파일 문법 검사 통과.
- `npm test`: 이동 경로 215개, 충돌 표본 47,239개, NPC 동선 표본 2,061개, 직원 위치 100개의 중복·경계 검사 통과. 옷을 바꿔도 이름·얼굴 유지, 세션별 코디 저장, 체험 데이터 분리, 초기화, 저장 실패 처리 검증 통과. 오디오 수명주기 25개 검증, 정적 파일·API·404·CORS 54개 확인 통과.
- `npm pack --dry-run`: 배포 패키지에 새 옷장 모듈 두 개를 포함하는지 확인.
- 음원은 첫 사용자 조작 전에는 AudioContext를 만들지 않습니다. 같은 오디오 그래프를 재사용하고, 종료된 노드를 정리하며, 겹친 이벤트의 우선순위와 반복 재생 간격을 확인했습니다.

## 실제 브라우저 확인

1.8.0에서 새로 확인한 내용입니다. 터치 검증은 Chromium의 모바일·터치 환경으로 진행했습니다.

| 항목 | 확인 내용 |
| --- | --- |
| 여섯 코디 | 모든 옷 적용, 얼굴·이름 유지, 새로고침 후 복원, 원래 옷으로 되돌리기 |
| 캐릭터 미리보기 | 앞·양옆·뒤 네 방향이 서로 다른 그림으로 표시 |
| 키보드 | 옷 선택 버튼에 방향키로 이동하고 Enter로 적용. 목록 복귀 시 원래 직원 카드에 포커스 복귀 |
| 작업 중 갱신 | 옷을 고르는 중에는 선택과 포커스 유지. 메모 입력 중 실시간 데이터가 갱신되어도 입력 내용 보존 |
| 언어 전환 | 옷장이 열린 상태에서 한국어·영어 전환, 열린 상태 유지 |
| 글자 대비 | 실제 렌더링 색 기준, 작업명 14.94:1 / 11.58:1, 코디명 5.08:1 / 4.61:1 (밝은 / 어두운 테마) |
| 작은 화면 | 320·360·390·540·768·1024·1440px에서 옷장과 상세 화면의 가로 넘침 없음 |
| 테마 전환 | 모바일 상단 높이 유지, 상세 이동 버튼과 통계의 이름·Ollama 막대 표시 확인 |
| 알림 | 모바일 직원 화면에서는 반복 알림을 생략. 확인 요청은 하단 메뉴 위에 표시하고, 누르면 해당 직원 상세로 이동 |
| 맵에서 보기 | 터치로 옷을 바꾸고 해당 직원에게 이동. 확대된 맵의 보이는 영역 안에 직원 표시 |
| 회전·동작 줄이기 | 390×844에서 844×390으로 회전, 가로 넘침 없음. 동작 줄이기 상태에서 코디 선택과 맵 이동 동작 |
| 오프라인 | 옷장 모듈을 포함한 셸 자산 55개. 오프라인 새로고침 후 옷 변경 가능, 연결 복귀 확인 |
| 런타임 | 위 검증과 캡처 과정에서 JavaScript 예외 없음 |

아래는 1.7.0에서 확인한 맵·오디오·기본 기능의 기록입니다. 1.8.0에서도 자동 검사와 캡처 과정의 주요 조작을 다시 확인했습니다. 모든 항목을 새로 실기기 검증한 것은 아닙니다.

| 항목 | 확인 내용 |
| --- | --- |

| 맵 구역 이동 | 작업실·회의 자리·자료실·테라스 확대, 키보드 선택, 전체 보기 복귀, 화면 회전 후 위치 맞춤 확인 |
| 맵 가림 | 확대된 맵과 Pixi 효과가 제목·상태 정보·하단 조작부를 덮지 않도록 같은 영역으로 제한 |
| 맵만 보기 | 헤더와 패널을 숨겨 맵을 넓게 표시. 데스크톱과 모바일에서 장면 버튼으로 원래 화면 복귀 |

| 자리 재배정 | 한 직원의 퇴근과 새 직원의 출근을 같은 데이터 갱신에 반영. 기존 직원 위치 유지, 6명 모두 서로 다른 자리 사용 |
| 작은 화면과 회전 | 320×568·375×667·390×844·844×390에서 라디오와 메뉴 표시, 패널 상태 전환 확인 |
| 긴 작업명 | 긴 한국어 문장과 공백 없는 영문 식별자 혼합. 본문 누락 없이 카드 안에서 줄바꿈 |
| 직원 목록 | 모바일에서 전체 너비 사용, 상세 보기와 목록 전환, 갱신 후 키보드 선택 유지 |
| 터치 조작 | 캐릭터 중심에서 17px 벗어난 실제 터치 입력으로 선택. 상세를 닫으면 원래 카드로 포커스 복귀 |
| 프라이버시 | 새 프로젝트명·작업명 요소에도 가림 적용 |
| 첫 실행 | 안내 화면 표시, 닫기와 키보드 이동 확인 |
