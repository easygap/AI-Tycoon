# 1.6.0 확인 기록

확인일: 2026년 9월 22일. 로컬 환경은 Windows, Node.js 24.14.0, Playwright로 실행한 Chromium입니다.

## 자동 검사

- `npm run build`: Tailwind CSS 생성 완료.
- `npm run lint`: JavaScript 42개 파일 문법 검사 통과.
- `npm test`: 오디오 수명주기 25개 검증, 정적 파일·API·404·CORS 50개 확인 통과.
- 음원은 첫 사용자 조작 전에는 AudioContext를 만들지 않습니다. 같은 오디오 그래프를 재사용하고, 종료된 노드를 정리하며, 겹친 이벤트의 우선순위와 반복 재생 간격을 확인했습니다.

## 실제 브라우저 확인

| 항목 | 확인 내용 |
| --- | --- |
| 화면 너비 | 320·360·390·540·768·1024·1440px에서 페이지 가로 넘침 없음 |
| 작은 화면과 회전 | 320×568·375×667·390×844·844×390에서 라디오와 메뉴 표시, 패널 상태 전환 확인 |
| 긴 작업명 | 긴 한국어 문장과 공백 없는 영문 식별자 혼합. 본문 누락 없이 카드 안에서 줄바꿈 |
| 직원 목록 | 모바일에서 전체 너비 사용, 상세 보기와 목록 전환, 갱신 후 키보드 선택 유지 |
| 터치 조작 | 캐릭터 중심에서 18px 벗어난 실제 터치 입력으로 선택. 상세를 닫으면 원래 카드로 포커스 복귀 |
| 프라이버시 | 새 프로젝트명·작업명 요소에도 가림 적용 |
| 첫 실행 | 안내 화면 표시, 닫기와 키보드 이동 확인 |
| 라디오 | 첫 클릭으로 실제 오디오 신호 발생. 새로고침 후 재생 재개, 모바일 전체 음소거 해제, 분위기 선택, 효과음 설정, `M` 음소거 확인 |
| 설정 | 모바일에서 설정 열기·닫기, 모달 내부 포커스 확인 |
| 단축키 충돌 | `Shift+P`는 프라이버시만 전환하고 스크린샷을 다운로드하지 않음 |
| 체험 모드 | 실제 WebSocket 데이터가 체험 화면을 덮어쓰지 않음. 체험 종료 후 최근 실제 상태 복원 |
| 기록 분리 | 체험 중 작업 이벤트와 테마 조작이 실제 통계·업적을 바꾸지 않음 |
| 동작 줄이기 | 운영체제 설정에 따라 상태와 효과 단계가 함께 변경 |
| 외부 요청 | 외부 요청을 차단한 상태에서 동작. 필요한 아이콘 모두 로컬에서 표시 |
| 오프라인 | 셸 자산 52개 캐시, 오프라인 새로고침 후 글꼴·아이콘·캐릭터 표시, 연결 복귀 확인 |
| 런타임 | 검증 흐름에서 JavaScript 예외 없음 |

README의 캡처는 실제 렌더링 결과입니다. 각 플랫폼의 실제 AI 도구를 모두 설치해 장시간 실행한 검증과 iOS Safari 실기기 검증은 이번 확인 범위에 포함하지 않았습니다. 감지 정확도는 도구별 세션 형식과 운영체제에 따라 달라집니다.
